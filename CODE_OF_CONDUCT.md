# Code of Conduct

## Our expectation

Be respectful. This project involves healthcare-domain code and data
modeling, and contributors and users may come from a wide range of
backgrounds and experience levels — treat everyone accordingly.

In short:

- Be considerate and constructive in issues, pull requests, and reviews.
- Disagree about code and decisions, not about people.
- No harassment, personal attacks, discriminatory language, or
  unwelcome contact of any kind.
- Respect that this is a small/solo-maintained project — response times
  may be slow, and that isn't a reason for hostility.

## Scope

This applies to all project spaces: issues, pull requests, code review
comments, and any other official project communication channels.

## Reporting

If someone's behavior in this project violates this code of conduct,
report it privately to the maintainer (see the repository's GitHub profile
for current contact details). Include what happened and where.

## Enforcement

The maintainer will review reports and may take any action deemed
appropriate, including warning the user, removing content, or blocking
further participation in the project.

This is a lightweight policy proportional to the project's current size —
it may be expanded if the contributor base grows.
