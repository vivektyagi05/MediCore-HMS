# Code of Conduct

## Our commitment

MediCore HMS is an actively developed healthcare-domain software project. We want project spaces to remain respectful, constructive, and welcoming to people with different backgrounds, identities, and levels of experience.

Everyone participating in project spaces is expected to help create a professional environment, regardless of role or experience.

## Expected behavior

- Be respectful, considerate, and constructive in issues, pull requests, reviews, and discussions.
- Critique code, technical decisions, and proposals—not people.
- Explain disagreements in good faith and remain open to evidence and correction.
- Respect privacy. Never post real patient data, credentials, payment details, or other sensitive information.
- Respect maintainer and contributor time. This is a small, actively developed project, so responses may not be immediate.
- Follow the repository's security-reporting process when sharing a potential vulnerability.

## Unacceptable behavior

Harassment, threats, personal attacks, discriminatory or hateful language, doxxing, unwelcome contact, deliberate disruption, and publishing private or sensitive information without authorization are not acceptable.

## Scope

This Code of Conduct applies to project spaces, including GitHub issues, pull requests, code reviews, discussions, commits, and other channels used for official project communication. It also applies when someone is representing the project in a public setting.

## Reporting a concern

Report conduct concerns privately to the maintainer using the contact information available through the repository owner's GitHub profile. Please include relevant links, dates, context, and any information needed to understand what happened. Share only information necessary to investigate the concern.

Do not use a public issue to report a security vulnerability; follow [`SECURITY.md`](SECURITY.md) instead. If a report concerns the maintainer, use GitHub's available reporting or support mechanisms where appropriate.

## Enforcement

The maintainer will review reports as fairly and promptly as reasonably possible, while recognizing that this project does not have a dedicated moderation team. Responses may include a warning, removal of content, restrictions on participation, or a ban from project spaces. The response will depend on the nature and severity of the behavior.

Retaliation against someone who raises a concern in good faith is not acceptable.

## Project context

This policy is intentionally proportionate to the project's current size and may be revised as the contributor community grows. It does not promise a particular response time or replace applicable platform policies.
