# P11 delivery notes

- Public experience is white-first/high-legibility; authenticated workspaces are unchanged.
- Public pages reuse the existing P11 component foundation.

- Run `npm run lint`, `npm run build`, and `npm run test:backend` after `npm install` in the target environment.
